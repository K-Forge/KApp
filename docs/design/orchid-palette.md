# Paleta orquídea

El portal de administración usó esta paleta en modo claro hasta el 2026-09-30. Brian la guardó
para la personalización de las apps móviles; el portal pasó al morado del modo oscuro, más claro.

Es el rosa institucional de la K llevado a medio camino hacia el morado: OKLCH con matiz 338.
El fondo tiene luminosidad 0,875 y croma 0,062. Todos los contrastes cumplen WCAG AA.

| Token | Color | Uso |
|---|---|---|
| `--bg` | `#f2c7e4` | Fondo |
| `--bg-elevated` | `#ffffff` | Tarjetas |
| `--bg-inset` | `#fae6f3` | Hundido (bloques de código, campos) |
| `--bg-hover` | `#efc1e0` | Al pasar el cursor |
| `--border` | `#ddb7d1` | Bordes |
| `--border-strong` | `#b285a4` | Bordes marcados |
| `--text` | `#251420` | Texto (11,8:1 sobre el fondo) |
| `--text-muted` | `#5e4456` | Texto secundario |
| `--text-faint` | `#6c5164` | Texto tenue (4,69:1 sobre el fondo, 7,0:1 sobre una tarjeta) |
| `--nav-bg` | `#fbdef1` | Menú lateral |
| `--nav-active-bg` | `#e8a5d4` | Sección activa del menú |
| `--nav-active-text` | `#59134a` | Texto de la sección activa (6,7:1) |
| `--nav-active-edge` | `#D51A65` | Borde de la sección activa: el rosa de la K |
| `--scrim` | `rgb(37 20 32 / 0.45)` | Detrás de un cajón o un diálogo |

Los acentos siguen los de la marca: teal `#539392` y `#2f5e5d` para las acciones, rosa `#D51A65`
y verde `#C9D329`.
