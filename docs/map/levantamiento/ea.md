# EA · Edificio Administrativo

**Fotos:** 3 — PI del P2, del P3 y del P4. No hay PE ni RS: el edificio no tiene planos a la vista.

**Archivos:** `EA-P2-PI` · `EA-P3-PI` · `EA-P4-PI`

**Estado:** solo inventario. **Todo se levanta a mano en sitio.**

## Lo que vale para todo el edificio

- **Las placas se titulan "Edificio Administrativo"** y listan dependencias, no salones. Ninguna
  trae números de puerta.
- **No hay placa del P1** entre las fotos. Tampoco se sabe si hay más pisos por encima del P4.
- **Son oficinas administrativas,** no espacios de clase. Para el estudiante importan sobre todo
  las ventanillas: Contabilidad, Recursos Humanos, Nómina, Planta Física, TIC, Seguridad.
